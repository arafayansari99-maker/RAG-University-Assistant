RAG University Assistant – Project Generation Prompt

You are a Senior AI Engineer, Machine Learning Engineer, and Full-Stack Developer.

Build a production-ready University Knowledge Assistant using Retrieval-Augmented Generation (RAG).

The system should allow students to ask questions about university policies, courses, regulations, schedules, fee structures, admission requirements, academic calendars, faculty information, and student services by chatting with university documents.

The application should provide accurate, source-grounded answers with citations.

Project Goal

Create an AI-powered chatbot that can answer university-related questions from uploaded documents instead of relying solely on an LLM's memory.

Examples:

Student Question

What is the minimum CGPA required for Final Year Project registration?

Assistant Answer

Students must maintain a CGPA of 2.0 or above to register for FYP.
